推荐方案 · 无需 7-Zip

Linux 直接解压 tar.gz 分卷

把 backup.tar.gz.001、.002 等全部分卷放到同一目录。通过管道直接解压，不生成额外的大文件。

Shell / BusyBox
mkdir -p output
cat backup.tar.gz.??? | tar -xz -C output
适用于三位编号的 .001～.999 分卷。不能单独解压其中一卷；注意按编号顺序合并。
零依赖 · x86-64 / ARM64 / ARMv7

没有 tar、gzip、7z 时

将发布包中的 extract.sh 与对应架构的 extract-linux-* 解压器拷贝到 Linux 目录，与全部分卷放在一起。

Shell · 自动选择 CPU 架构
chmod +x ./extract-linux-*
sh ./extract.sh backup.tar.gz.001 ./output
解压程序为静态编译版本，无需 Python、7-Zip 或 tar；可校验分卷连续性和 gzip CRC32。
备选方法 · 需要额外磁盘空间

先合并成普通 tar.gz

先将分卷顺序拼接成一个完整文件，再用 tar 解压；适用于需要保留归档副本的情况。

Shell
cat backup.tar.gz.??? > backup.tar.gz
mkdir -p output
tar -xzf backup.tar.gz -C output
确保磁盘剩余空间足够容纳完整的 tar.gz 文件；超过 .999 卷时建议使用独立解压器。
仅适用于 7z 分卷格式

使用 7z 命令解压

只有压缩时选择了 7z 分卷 才使用这条命令。默认 tar.gz 格式无需安装 7-Zip。

Linux / Windows
7z x backup.7z.001 -ooutput
请勿用 7z 命令直接解压默认的 .tar.gz.001；应使用上面的 Linux 方案。
常见问题

所有分卷必须完整、从 .001 连续编号并放在同一目录。文件名含空格时请正确引用路径。
